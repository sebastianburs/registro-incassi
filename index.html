Sorgente dati · GitHub

Il CSV vive nel tuo repo GitHub. Incolla un token una volta (resta solo nel tuo browser) e salvi con un bottone — nessun altro sistema.

⚙ Configurazione repository e token

Token: GitHub → Settings → Developer settings → Fine-grained tokens → repo registro-incassi, permesso Contents: Read and write. Salvato solo in localStorage del browser, inviato solo a api.github.com.
Password dati: cifra/decifra il CSV in locale (AES-256), non è mai salvata né committata. Il file nel repo (data/registro.csv.enc) è illeggibile senza di essa.
